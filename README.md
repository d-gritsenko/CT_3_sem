# CT_3_sem — Системное программирование в Linux (3 семестр)

Сборник лабораторных и практических работ по курсу компьютерных технологий (C, POSIX, System V IPC, сокеты, SQLite3, GTK 3).

## Структура репозитория

- [`chat/`](./chat) Многопользовательский консольный чат на базе разделяемой памяти (`shm`), семафоров (`sem`), потоков (`pthread`) и неканонического режима терминала (`termios`).
- [`runsim/`](./runsim) Утилита ограничения числа одновременно запущенных процессов с поддержкой пространств имён PID (`PID namespaces`).
- [`socket_lab/`](./socket_lab) Работа с локальными и сетевыми сокетами (`AF_UNIX`, `AF_INET`, `SOCK_STREAM`, `SOCK_DGRAM`, мультиплексирование `select`).
- [`queue/`](./queue) Мессенджер **DeepSpeak** поверх очередей сообщений System V (`sys/msg.h`) и разделяемой памяти (`sys/shm.h`) с базой данных **SQLite3** и графическим интерфейсом **GTK 3**:
  - `2_Q.c` Базовый парный чат через `fork()` по числовым `mtype`;
  - `protocol.h` Общий бинарный протокол (авторизация, личные сообщения, многопользовательские комнаты, история, удаление чатов, статусы прочтения, передача файлов через `shm`) и общие `inline`-хелперы (`copy_utf8_safe`, таймстемпы, работа с Shared Memory);
  - `db.h` / `db.c` Модуль хранения на SQLite3 (`users.db`): солёное хэширование паролей, резерв отладочных аккаунтов `user*`, сохранение выбранной темы, истории личных переписок, комнат и вложений, удаление истории со стороны пользователя и постоянный учёт непрочитанных сообщений;
  - `extraq.c` Процесс-арбитр с защитой от повторного запуска (`flock`) и консольный клиент (`pthread`): регистрация/вход (`#`/`@`), маршрутизация сообщений, передача файлов через `shm` (`/sendfile`, `/getfile`), `heartbeat`, список онлайн (`CMD_WHO`), многопользовательские комнаты (`/join`, `/leave`, `/rooms`, `/r`), история и удаление (`/history`, `/delchat`), подтверждения прочтения (`CMD_ACK`, `CMD_MARK_READ`);
  - `gui_client.c` Десктопный клиент **DeepSpeak** на **GTK 3**: экран входа/регистрации, меню `☰` (инфо об аккаунте, авто/ручной масштаб шрифта, 5 тёмных тем на лету с сохранением в БД, выход), меню чата `⋮` с подтверждением удаления, контекстная кнопка `+` / `📎` (новый чат или прикрепление фото/файлов), инлайн-превью фотографий (`GdkPixbuf`), вкладки `Users | Rooms` с постоянными счётчиками непрочитанных и статусы прочтения (`✓` → `✓✓`), включая офлайн-сообщения.

## Сборка

В каждой директории есть собственный `Makefile`. Для сборки проекта `queue/` целиком (арбитр с SQLite3 + GUI на GTK 3):

```bash
sudo apt install libsqlite3-dev libgtk-3-dev pkg-config
cd queue
make
```
