# DeepSpeak — System V Message Queues

Десктопный и консольный мессенджер **DeepSpeak**, построенный поверх единой очереди сообщений System V (`sys/msg.h`), потоков POSIX (`pthread`), локальной базы данных **SQLite3** и графического интерфейса **GTK 3**.

## Состав

- **`protocol.h`** — общий бинарный протокол: ключ очереди (`ftok("/tmp", 'Q')`), структура `struct qmsg` с таймстемпами (`timestamp`), коды команд (`CMD_REGISTER`, `CMD_LOGIN`, `CMD_SET_THEME`, `CMD_CHAT`, `CMD_HISTORY`, `CMD_HISTORY_ITEM`, `CMD_DELETE_CHAT`, `CMD_DELETE_ROOM`, `CMD_MARK_READ`, `CMD_ACK`, `CMD_WHO`, команды комнат `CMD_ROOM_*`), путь к БД (`users.db`), лимит комнат (`MAX_ROOMS 16`), lock-файл арбитра (`/tmp/queue_arbiter.lock`) и безопасная UTF-8 обрезка строк (`copy_utf8_safe`).
- **`db.h` / `db.c`** — модуль хранения на **SQLite3** (`users.db`, исключён из Git через `.gitignore`):
  - таблица `users`: регистрация и аутентификация с 256-битным солёным хэшированием паролей (соль из `/dev/urandom`, сравнение за константное время), сохранение выбранной темы (`theme_id`) и автозаполнение стартовыми аккаунтами при первом запуске (`dmitry` / `123456`, `alice` / `alice123`, `bob` / `bob123`);
  - зарезервированный отладочный префикс `user*` (без учёта регистра): регистрация запрещена, вход разрешён без записи в БД по отладочному паролю (`debug123` или из переменной окружения `QUEUE_DEBUG_PASS`), переписки и темы отладочных аккаунтов в базе не сохраняются;
  - таблицы `messages`, `room_messages`, `room_members`, `room_cleared`, `room_read`: хранение истории личных чатов и комнат, восстановление состава комнат при входе, постраничное удаление переписок со стороны пользователя (с физической очисткой в БД, когда историю удалили обе стороны или все участники комнаты) и постоянный учёт статуса прочтения (`is_read`, `last_read_id`) с автоматической миграцией схемы.
- **`extraq.c`** — процесс-арбитр и многопоточный консольный клиент (`pthread`):
  - защита от запуска второго экземпляра арбитра через `flock` (`/tmp/queue_arbiter.lock`);
  - авторизация через SQLite3 (`CMD_REGISTER`, `CMD_LOGIN`), отладочный режим `[DEBUG]` для `user*` и маршрутизация личных сообщений через арбитра с сохранением в БД;
  - контроль активности (`heartbeat` каждые 4 с, таймаут 10 с) и список пользователей онлайн (`CMD_WHO`);
  - многопользовательские комнаты с сохранением истории и автовосстановлением участия при повторном входе;
  - синхронизация статусов прочтения (`CMD_MARK_READ` и `CMD_ACK`, включая массовое подтверждение `msg_id = 0` при прочтении офлайн-сообщений);
  - офлайн-буфер (`chat_backlog.dat`, TTL 60 с) для отладочных аккаунтов;
  - цветной CLI-интерфейс с таймстемпами (`[HH:MM:SS]` и `[DD.MM HH:MM]` для прошлых дней).
- **`gui_client.c`** — десктопный клиент **DeepSpeak** на **GTK 3** с экраном авторизации, живым переключением тем, историей переписок и полной совместимостью с консольным клиентом `./extraq client`.
- **`2_Q.c`** — базовый парный чат между двумя терминалами по числовым `mtype` через `fork()`.

## Зависимости

Для сборки арбитра и графического клиента в Ubuntu требуются SQLite3, GTK 3 и `pkg-config`:

```bash
sudo apt update
sudo apt install libsqlite3-dev libgtk-3-dev pkg-config
```

## Сборка

```bash
make          # собрать всё (2_Q, extraq, gui_client)
make extraq   # собрать только арбитра и консольный клиент (SQLite3 + pthread)
make gui      # собрать только графический клиент (GTK 3)
make clean    # удалить бинарники
```

## Запуск

### Арбитр (обязательно запускается первым)

```bash
./extraq arbiter
```

При необходимости можно переопределить отладочный пароль для аккаунтов `user*`:

```bash
QUEUE_DEBUG_PASS=mysecret ./extraq arbiter
```

Повторный запуск арбитра блокируется через `flock`. Остановка (`Ctrl+C`) сохраняет бэклог, корректно закрывает `users.db`, удаляет очередь из ядра и снимает lock-файл.

### Графический клиент (GTK 3)

Запускается из отдельного терминала (флаг `&` открывает окно в фоне, не блокируя консоль):

```bash
./gui_client &
./gui_client &
```

- **Экран авторизации** — отдельная стартовая карточка входа и регистрации (`Username`, скрытое поле `Password`, кнопки `Log In` и `Register`, отображение ошибок и подсказка по отладочным аккаунтам `user*`).
- **Верхняя панель чата** — текущий статус и никнейм (с пометкой `[DEBUG]` для `user*`), выпадающий список тем оформления и кнопка `Logout`.
- **5 тёмных тем на лету** — `Catppuccin Mocha`, `Nord Dark`, `Gruvbox Dark`, `Tokyo Night`, `Cyber Dark` с мгновенным обновлением CSS, буферов и сайдбара; выбранная тема автоматически сохраняется в `users.db` и восстанавливается при следующем входе.
- **История и удаление чатов** — при входе автоматически подгружаются личные переписки и комнаты из SQLite с оригинальным временем отправки; в шапке активного диалога доступны кнопки `Delete Chat` / `Delete Room` (и `Leave` для комнат).
- **Правая панель `Users | Rooms`** — переключение между личками (`●` онлайн / `○` офлайн) и комнатами (`#room (N)` / `+ #room (N)` для быстрого входа) с постоянными счётчиками непрочитанных, которые сохраняются даже после `Logout` и перезапуска.
- **Статусы прочтения (в стиле Telegram)** — `✓` при отправке, переход в `✓✓` при прочтении собеседником (включая автоматическое обновление всех висящих `✓` → `✓✓`, когда офлайн-получатель возвращается в сеть и открывает чат).
- **Надёжность** — неблокирующая отправка (`IPC_NOWAIT`) с обработкой переполнения очереди (`EAGAIN`), безопасная UTF-8 обрезка строк для кириллицы и эмодзи, автоматический `logout` при закрытии окна.

### Консольный клиент (терминал)

Может работать параллельно с `gui_client` через одного арбитра:

```bash
./extraq client
```

Команды:
- `#<ник> <пароль>` — регистрация нового аккаунта в `users.db`;
- `@<ник> <пароль>` — вход в существующий или отладочный (`user*`) аккаунт;
- `<ник>#<текст>` — отправка личного сообщения;
- `/join <комната>` — создать или войти в комнату;
- `/leave <комната>` — выйти из комнаты;
- `/rooms` — список активных комнат (`*` — комнаты, в которых вы состоите);
- `/r <комната> <текст>` — отправить сообщение в комнату;
- `/history [ник|#комната]` — загрузить историю переписки из БД;
- `/delchat <ник|#комната>` — удалить историю чата или комнаты для себя;
- `?` или `/who` — список пользователей онлайн;
- `##` — выход из аккаунта;
- `Ctrl+D` — завершение клиента.

### Базовый чат `2_Q`

Запускать из директории с `2_Q.c`:

```bash
./2_Q 1 2   # терминал 1
./2_Q 2 1   # терминал 2
```
