# System V Message Queues

Межпроцессное взаимодействие через единую очередь сообщений System V (`sys/msg.h`).

## Состав

- **`protocol.h`** Общий бинарный протокол: ключ очереди (`ftok("/tmp", 'Q')`), `struct qmsg`, коды команд (`CMD_*`), таймауты, путь к lock-файлу арбитра (`/tmp/queue_arbiter.lock`) и безопасная UTF-8 обрезка строк (`copy_utf8_safe`).
- **`2_Q.c`** Базовый парный чат между двумя терминалами по числовым `mtype` через `fork()`.
- **`extraq.c`** Процесс-арбитр и многопоточный консольный клиент (`pthread`):
  - защита от запуска второго экземпляра арбитра через `flock` (`/tmp/queue_arbiter.lock`);
  - раздельная регистрация (`CMD_REGISTER`) и переподключение (`CMD_RECONNECT`) с закреплением персонального `mtype` (`id`) за никнеймом на время сессии арбитра;
  - зарезервированное системное имя `arbiter`, запрет отправки сообщений самому себе и арбитру;
  - контроль активности (`heartbeat` каждые 4 с, таймаут 10 с);
  - список пользователей онлайн (`CMD_WHO`);
  - офлайн-буфер (`TTL` 60 с) с перехватом недоставленных сообщений при таймауте/выходе и атомарным сохранением на диск (`chat_backlog.dat`) при перезапуске арбитра;
  - подтверждения доставки и прочтения (`CMD_ACK`), безопасная UTF-8 обрезка (`copy_utf8_safe`);
  - цветной CLI-интерфейс с таймстемпами `[HH:MM:SS]`.
- **`gui_client.c`** Десктопный клиент на **GTK 3** с англоязычным интерфейсом, работающий поверх той же очереди System V (полностью совместим с `./extraq client`).
