# CT_3_sem — Системное программирование в Linux (3 семестр)

Сборник лабораторных и практических работ по курсу компьютерных технологий (C, POSIX, System V IPC, сокеты, SQLite3, GTK 3).

## Структура репозитория

- [`chat/`](./chat) Многопользовательский консольный чат на базе разделяемой памяти (`shm`), семафоров (`sem`), потоков (`pthread`) и неканонического режима терминала (`termios`).
- [`runsim/`](./runsim) Утилита ограничения числа одновременно запущенных процессов с поддержкой пространств имён PID (`PID namespaces`).
- [`socket_lab/`](./socket_lab) Работа с локальными и сетевыми сокетами (`AF_UNIX`, `AF_INET`, `SOCK_STREAM`, `SOCK_DGRAM`, мультиплексирование `select`).
- [`queue/`](./queue) Мессенджер **DeepSpeak** поверх очередей сообщений System V (`sys/msg.h`) с базой данных **SQLite3** и графическим интерфейсом **GTK 3**:
  - `2_Q.c` Базовый парный чат через `fork()` по числовым `mtype`;
  - `protocol.h` Общий бинарный протокол (авторизация, личные сообщения, многопользовательские комнаты, история, удаление чатов, статусы прочтения), ключ очереди (`ftok("/tmp", 'Q')`), lock-файл арбитра (`/tmp/queue_arbiter.lock`) и безопасная UTF-8 обрезка строк (`copy_utf8_safe`);
  - `db.h` / `db.c` Модуль хранения на SQLite3 (`users.db`): солёное хэширование паролей, резерв отладочных аккаунтов `user*`, сохранение выбранной темы, истории личных переписок и комнат, постраничное удаление истории со стороны пользователя и постоянный учёт непрочитанных сообщений;
  - `extraq.c` Процесс-арбитр с защитой от повторного запуска (`flock`) и консольный клиент (`pthread`): регистрация/вход (`#`/`@`), маршрутизация сообщений через арбитра, `heartbeat`, список онлайн (`CMD_WHO`), многопользовательские комнаты (`/join`, `/leave`, `/rooms`, `/r`), история и удаление (`/history`, `/delchat`), подтверждения прочтения (`CMD_ACK`, `CMD_MARK_READ`);
  - `gui_client.c` Десктопный клиент **DeepSpeak** на **GTK 3**: стартовый экран входа/регистрации, раздельные диалоги и вкладки `Users | Rooms`, 5 встроенных тёмных тем с переключением на лету и сохранением в БД (`Catppuccin Mocha`, `Nord Dark`, `Gruvbox Dark`, `Tokyo Night`, `Cyber Dark`), восстановление истории и счётчиков непрочитанных, удаление чатов/комнат и статусы прочтения (`✓` → `✓✓`), включая офлайн-сообщения.

## Сборка

В каждой директории есть собственный `Makefile`. Для сборки проекта `queue/` целиком (арбитр с SQLite3 + GUI на GTK 3):

```bash
sudo apt install libsqlite3-dev libgtk-3-dev pkg-config
cd queue
make
```
