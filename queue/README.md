# System V Message Queues

Обмен сообщениями между процессами через одну очередь сообщений System V (`sys/msg.h`).

## Состав

- **`2_Q.c`** — базовый чат между терминалами по числовым идентификаторам (`mtype`). Через `fork()` один процесс принимает сообщения на свой ID, второй читает `stdin` и отправляет на ID собеседника.
- **`extraq.c`** — мессенджер с процессом-арбитром и многопоточными клиентами (`pthread`):
  - регистрация по именам и выдача уникальных `mtype`;
  - контроль активности (`heartbeat` каждые 4 с, таймаут 10 с);
  - буферизация сообщений для офлайн- и вылетевших пользователей (`TTL` 60 с) с автоматической доставкой при повторном входе;
  - консольный интерфейс с таймстемпами, цветами и строкой приглашения.

## Сборка

`Makefile` автоматически собирает все `.c`-файлы в директории (`gcc -Wall -Wextra -pthread`):

```bash
make          # собрать все программы (2_Q, extraq)
make 2_Q      # собрать только 2_Q
make extraq   # собрать только extraq
make clean    # удалить бинарники
