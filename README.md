# CT_3_sem

Лабораторные работы и учебные проекты по курсу «Компьютерные технологии» (3 семестр). Системное программирование на C под Linux.

## Содержание

| Проект | Описание |
| :--- | :--- |
| [`chat/`](./chat) | Модульный терминальный чат на C с поддержкой личных сообщений и механизмов IPC |
| [`runsim/`](./runsim) | Утилита контроля процессов с поддержкой PID namespace (`runsim`)
| [`socket_lab/`](./socket_lab) | Набор клиент-серверных программ для работы с локальными, TCP и UDP сокетами |
