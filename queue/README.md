# System V Message Queues

Межпроцессное взаимодействие через единую очередь сообщений System V (`sys/msg.h`).

## Состав

- **`protocol.h`** — общий бинарный протокол: ключ очереди (`ftok("/tmp", 'Q')`), `struct qmsg`, коды команд (`CMD_*`) и таймауты.
- **`2_Q.c`** — базовый парный чат между двумя терминалами по числовым `mtype` через `fork()`.
- **`extraq.c`** — процесс-арбитр и многопоточный консольный клиент (`pthread`):
  - регистрация уникальных никнеймов и выдача персональных `mtype`;
  - контроль активности (`heartbeat` каждые 4 с, таймаут 10 с);
  - офлайн-буфер (`TTL` 60 с) с атомарным сохранением на диск (`chat_backlog.dat`) при перезапуске арбитра;
  - подтверждения доставки сообщений (`CMD_ACK`);
  - цветной CLI-интерфейс с таймстемпами `[HH:MM:SS]`.
- **`gui_client.c`** — десктопный клиент на **GTK 3**, работающий поверх той же очереди System V (полностью совместим с `./extraq client`).
