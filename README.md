# CT_3_sem — Системное программирование в Linux (3 семестр)

Сборник лабораторных и практических работ по курсу компьютерных технологий (C, POSIX, System V IPC, сокеты, GTK 3).

## Структура репозитория

- [`chat/`](./chat) Многопользовательский консольный чат на базе разделяемой памяти (`shm`), семафоров (`sem`), потоков (`pthread`) и неканонического режима терминала (`termios`).
- [`runsim/`](./runsim) Утилита ограничения числа одновременно запущенных процессов с поддержкой пространств имён PID (`PID namespaces`).
- [`socket_lab/`](./socket_lab) Работа с локальными и сетевыми сокетами (`AF_UNIX`, `AF_INET`, `SOCK_STREAM`, `SOCK_DGRAM`, мультиплексирование `select`).
- [`queue/`](./queue) Межпроцессный обмен через очереди сообщений System V (`sys/msg.h`):
  - `2_Q.c` Базовый парный чат через `fork()` по числовым `mtype`;
  - `protocol.h` Общий бинарный протокол и ключ очереди (`ftok("/tmp", 'Q')`);
  - `extraq.c` Процесс-арбитр и консольный клиент (`pthread`) с `heartbeat`, подтверждениями доставки (`ACK`), офлайн-буфером (TTL 60 с) и сохранением бэклога на диск (`chat_backlog.dat`);
  - `gui_client.c` Десктопный графический клиент на **GTK 3**, полностью совместимый с консольным клиентом через общего арбитра.
