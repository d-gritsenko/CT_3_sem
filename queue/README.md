# System V Message Queues

Реализация обмена сообщениями между процессами через одну очередь сообщений System V (`sys/msg.h`).

## Состав

- **`2_Q.c`** — базовый чат между терминалами по числовым идентификаторам (`mtype`). Один процесс принимает сообщения со своим ID, второй (`fork`) читает ввод с клавиатуры и отправляет на ID собеседника.
- **`ExtraQ.c`** — расширенный чат с процессом-арбитром и многопоточными клиентами (`pthread`). Арбитр регистрирует клиентов по именам, выдаёт ID, проверяет активность раз в 10 секунд (heartbeat) и очищает очередь при выходе или таймауте абонента.

## Сборка

```bash
make          # собрать все доступные цели
