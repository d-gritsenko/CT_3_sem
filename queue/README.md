# System V Message Queues

Межпроцессное взаимодействие через единую очередь сообщений System V (`sys/msg.h`).

## Состав

- **`protocol.h`** — общий бинарный протокол: ключ очереди (`ftok("/tmp", 'Q')`), `struct qmsg`, коды команд (`CMD_*`, включая команды комнат `CMD_ROOM_JOIN`, `CMD_ROOM_LEAVE`, `CMD_ROOM_MSG`, `CMD_ROOM_LIST`), лимит комнат (`MAX_ROOMS 16`), таймауты, путь к lock-файлу арбитра (`/tmp/queue_arbiter.lock`) и безопасная UTF-8 обрезка строк (`copy_utf8_safe`).
- **`2_Q.c`** — базовый парный чат между двумя терминалами по числовым `mtype` через `fork()`.
- **`extraq.c`** — процесс-арбитр и многопоточный консольный клиент (`pthread`):
  - защита от запуска второго экземпляра арбитра через `flock` (`/tmp/queue_arbiter.lock`);
  - раздельная регистрация (`CMD_REGISTER`) и переподключение (`CMD_RECONNECT`) с закреплением персонального `mtype` (`id`) за никнеймом на время сессии арбитра;
  - зарезервированное системное имя `arbiter`, запрет отправки сообщений самому себе и арбитру;
  - контроль активности (`heartbeat` каждые 4 с, таймаут 10 с);
  - список пользователей онлайн (`CMD_WHO`);
  - многопользовательские комнаты: создание, вход, выход, список активных комнат и рассылка сообщений всем онлайн-участникам комнаты;
  - офлайн-буфер (`TTL` 60 с) с перехватом недоставленных сообщений при таймауте/выходе и атомарным сохранением на диск (`chat_backlog.dat`) при перезапуске арбитра;
  - подтверждения доставки и прочтения (`CMD_ACK`), безопасная UTF-8 обрезка (`copy_utf8_safe`);
  - цветной CLI-интерфейс с таймстемпами `[HH:MM:SS]`.
- **`gui_client.c`** — десктопный клиент на **GTK 3** с англоязычным интерфейсом, работающий поверх той же очереди System V (полностью совместим с `./extraq client`).

## Зависимости (для GUI)

Для сборки графического клиента в Ubuntu требуются заголовочные файлы GTK 3 и `pkg-config`:

```bash
sudo apt update
sudo apt install libgtk-3-dev pkg-config
```

## Сборка

```bash
make          # собрать всё (2_Q, extraq, gui_client)
make extraq   # собрать только консольную версию (без GTK)
make gui      # собрать только графический клиент (gui_client)
make clean    # удалить бинарники
```

## Запуск

### Арбитр (обязательно запускается первым)

```bash
./extraq arbiter
```

Повторный запуск арбитра блокируется через `flock`. Остановка (`Ctrl+C`) сохраняет неотправленные офлайн-сообщения в `chat_backlog.dat`, удаляет очередь из ядра и снимает lock-файл.

### Графический клиент (GTK 3)

Запускается из отдельного терминала (флаг `&` открывает окно в фоне, не блокируя консоль):

```bash
./gui_client &
./gui_client &
```

- **Верхняя панель** — ввод никнейма (`Username`), кнопки `Register` и `Reconnect` (после входа заменяются на `Logout`). Нажатие `Enter` при первом входе вызывает `Register`, а после `Logout` — `Reconnect`.
- **Раздельные диалоги** — для каждого собеседника и каждой комнаты хранится отдельная история переписки; сверху закреплён `★ System` для системных событий, а над лентой отображается заголовок активного чата (`Chat with <user> (online/offline)` или `#<room> (N members)` с кнопкой `Leave`).
- **Правая панель с вкладками `Users | Rooms`** — переключение между личками и комнатами с общими счётчиками непрочитанных на кнопках вкладок:
  - во вкладке **`Users`** — список собеседников с цветными индикаторами статуса (`●` онлайн / `○` офлайн) и жёлтой подсветкой непрочитанных сообщений;
  - во вкладке **`Rooms`** — поле ввода + кнопка `Join` для создания/входа в комнату и список активных комнат (`#room (N)` для своих, `+ #room (N)` для быстрого входа по клику).
- **Нижняя панель** — поля `To / #room`, `Message...` и кнопка `Send` (отправка по кнопке или `Enter`).
- **Статусы прочтения (в стиле Telegram)** — `✓` для отправленных сообщений, переход в `✓✓` по `CMD_ACK`, когда получатель (или хотя бы один участник комнаты) открывает диалог.
- **Надёжность** — неблокирующая отправка (`IPC_NOWAIT`) с обработкой переполнения очереди (`EAGAIN`), безопасная UTF-8 обрезка строк для кириллицы и эмодзи, автоматический `logout` и очистка локальной истории при выходе/закрытии окна.

### Консольный клиент (терминал)

Может работать параллельно с `gui_client` через одного арбитра:

```bash
./extraq client
```

Команды:
- `#<никнейм>` — регистрация нового пользователя;
- `@<никнейм>` — переподключение под существующим офлайн-ником;
- `<никнейм>#<текст>` — отправка личного сообщения;
- `/join <комната>` — создать или войти в комнату;
- `/leave <комната>` — выйти из комнаты;
- `/rooms` — список активных комнат (`*` — комнаты, в которых вы состоите);
- `/r <комната> <текст>` — отправить сообщение в комнату;
- `?` или `/who` — список пользователей онлайн;
- `##` — выход из имени;
- `Ctrl+D` — завершение клиента.

### Базовый чат `2_Q`

Запускать из директории с `2_Q.c`:

```bash
./2_Q 1 2   # терминал 1
./2_Q 2 1   # терминал 2
```
