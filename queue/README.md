# DeepSpeak (System V Message Queues)

Локальный многопользовательский мессенджер на C для Linux поверх очереди сообщений System V (`sys/msg.h`), разделяемой памяти (`sys/shm.h`) и SQLite3. Поддерживает консольный клиент и десктопный GUI на GTK 3.

## Состав

- `protocol.h` — общий бинарный протокол: ключ очереди (`ftok("/tmp", 'Q')`), `struct qmsg` (включая `session_token`), коды команд (`CMD_*`), лимиты (`MAX_CLIENTS 64`, `MAX_ROOMS 16`, `MAX_TEXT 255`), таймауты, хелперы для работы с `shm`, файловых маркеров, цитат и безопасной UTF-8 обрезки (`copy_utf8_safe`).
- `db.h` / `db.c` — слой хранения на SQLite3 (`users.db`):
  - учётные записи с солью и итеративным хешированием пароля (4096 раундов) и проверкой за константное время;
  - сохранение истории личных сообщений (DM) и комнат, статусов прочтения, флагов редактирования и локального удаления;
  - хранение состава комнат, метаданных (владелец, топик, закреплённое сообщение) и выбранной темы клиента;
  - поддержка debug-аккаунтов `user*` (пароль через `QUEUE_DEBUG_PASS`, по умолчанию `debug123`), работающих без записи в БД.
- `extraq.c` — процесс-арбитр (в обычном или фоновом daemon-режиме) и многопоточный консольный клиент (`pthread`):
  - защита от повторного запуска арбитра через `flock` (`/tmp/queue_arbiter.lock`) с записью PID;
  - управление фоновым процессом (`daemon`, `stop`, `status`) и запись логов в `arbiter.log`;
  - изоляция IPC-очереди правами `0600` и 64-битные сессионные токены из `/dev/urandom`, проверяемые в каждой команде;
  - антифлуд (лимит 8 сообщений/файлов за 5 с, мут на 10 с) и защита от брутфорса логина (блокировка на 30 с после 5 неверных попыток, затирание буфера пароля через `secure_zero`);
  - контроль активности (`heartbeat` каждые 4 с, таймаут 10 с), офлайн-буфер (TTL 60 с, `chat_backlog.dat`) для debug-сессий;
  - передача файлов через System V `shm` с хранением на сервере в `uploads/`.
- `gui_client.c` — десктопный клиент на GTK 3 (полностью совместим с `./extraq client`).
- `2_Q.c` — базовый парный чат между двумя терминалами по числовым `mtype` через `fork()`.

## Зависимости

Для сборки всех целей в Ubuntu требуются SQLite3, GTK 3 и `pkg-config`:

```bash
sudo apt update
sudo apt install libsqlite3-dev libgtk-3-dev pkg-config
```

## Сборка

```bash
make        # собрать всё (2_Q, extraq, gui_client)
make extraq # собрать только арбитр и консольный клиент (без GTK)
make gui    # собрать только графический клиент (gui_client)
make clean  # удалить бинарники
```

## Запуск

### Арбитр (запускается первым)

Рекомендуемый фоновый режим (демон):

```bash
./extraq daemon   # запуск в фоне (логи в arbiter.log)
./extraq status   # проверить статус и PID
./extraq stop     # корректно остановить по SIGTERM
```

Либо запуск в текущем терминале с выводом логов на экран:

```bash
./extraq arbiter
```

Повторный запуск блокируется через `flock`. При остановке (`./extraq stop` или `Ctrl+C`) сохраняются неотправленные сообщения debug-сессий (`chat_backlog.dat`), закрывается БД, удаляется очередь из ядра и снимается lock-файл.

### Графический клиент (GTK 3)

```bash
./gui_client &
```

Основные возможности GUI:
- **Экран авторизации** — вход (`Log In`) и регистрация (`Register`) по логину и паролю, живой обратный отсчёт при блокировке по лимиту попыток, автоочистка поля пароля при ошибке.
- **Меню `☰`** — информация об аккаунте и ID, настройка масштаба интерфейса (`Auto` или `10pt–18pt`), 5 тёмных тем оформления (`Catppuccin Mocha`, `Nord Dark`, `Gruvbox Dark`, `Tokyo Night`, `Cyber Dark`) с сохранением в БД, кнопка `Logout`.
- **Диалоги и боковая панель** — вкладки `Users` и `Rooms` со счётчиками непрочитанных, статусами онлайн/офлайн (`●` / `○`), системной лентой `★ System` и кнопкой `+` для быстрого открытия чата или комнаты.
- **Сообщения** — история из SQLite3, статусы доставки и прочтения (`✓` / `✓✓`), индикатор набора текста (`typing...`), поиск по переписке (`⋮ -> Search`, навигация `▲`/`▼`, выход по `Esc`).
- **Контекстное меню сообщения (ПКМ)** — цитирование (`Reply`), редактирование (`Edit`, пометка `(edited)`), удаление (`Delete`) и закрепление (`Pin` для владельца комнаты).
- **Комнаты** — окно `Members & Info` со списком участников и их статусами; владелец комнаты может менять топик, закреплять/откреплять сообщения (`📌`) и кикать участников (`Kick`).
- **Файлы и фото** — отправка через кнопку `📎` (`Photo` / `File`), встроенный предпросмотр картинок (PNG, JPG, GIF, WebP, BMP) прямо в чате и сохранение вложений по клику.

### Консольный клиент (терминал)

Работает параллельно с `gui_client` через одного арбитра:

```bash
./extraq client
```

Команды:
- `#<name> <pass>` — регистрация нового пользователя;
- `@<name> <pass>` — вход (для `user*` — debug-режим);
- `<name>#<text>` — отправка личного сообщения;
- `/join <room>` — создать или войти в комнату;
- `/leave <room>` — выйти из комнаты;
- `/rooms` — список активных комнат (`*` — комнаты, в которых вы состоите);
- `/r <room> <text>` — отправить сообщение в комнату;
- `/history [user|#room]` — загрузить историю переписки;
- `/delchat <user|#room>` — удалить историю чата или комнаты для себя;
- `/sendfile <user|#room> <path>` — отправить файл;
- `/getfile <file_id> [dest_path]` — скачать файл (по умолчанию в `downloads/`);
- `?` или `/who` — список пользователей онлайн;
- `##` — выход из аккаунта;
- `Ctrl+D` — завершение клиента.

### Базовый чат `2_Q`

```bash
./2_Q 1 2 # терминал 1
./2_Q 2 1 # терминал 2
```
